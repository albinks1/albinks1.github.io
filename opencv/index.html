OpenCV : blocs usuels

Charger et afficher une image

io

Lire input.jpg, l'afficher dans une fenêtre, attendre une touche, puis fermer les fenêtres.

Solution
import cv2
img = cv2.imread('../images/input.jpg')
cv2.imshow('image', img)
cv2.waitKey(0)
cv2.destroyAllWindows()
Fonctions
  • cv2.imread(filename, flags=cv2.IMREAD_COLOR) : Lit une image en BGR (uint8). Renvoie None si le fichier est introuvable.
  • cv2.imshow(winname, mat) : Affiche mat dans la fenêtre winname. Sans waitKey, la fenêtre ne se rafraîchit pas.
  • cv2.waitKey(delay=0) : Attend une touche pendant delay ms (0 = indéfiniment). Renvoie le code de la touche.
  • cv2.destroyAllWindows() : Ferme toutes les fenêtres OpenCV.

Convertir en niveaux de gris

couleur

Convertir l'image chargée en niveaux de gris et l'afficher.

Solution
import cv2
img = cv2.imread('../images/input.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
cv2.imshow('gray', gray)
cv2.waitKey(0)
cv2.destroyAllWindows()
Fonctions
  • cv2.cvtColor(src, code) : Convertit l'espace colorimétrique selon code (ici COLOR_BGR2GRAY). OpenCV charge en BGR, pas en RGB.

Enregistrer une image

io

Enregistrer l'image en niveaux de gris dans output.png.

Solution
import cv2
img = cv2.imread('../images/input.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
cv2.imwrite('output.png', gray)
Fonctions
  • cv2.imwrite(filename, img, params=None) : Écrit img sur disque, le format est déduit de l'extension. Renvoie True si l'écriture a réussi.

Redimensionner une image

géométrie

Réduire l'image de moitié et afficher ses dimensions avant et après.

Solution
import cv2
img = cv2.imread('../images/input.jpg')
print(img.shape)
small = cv2.resize(img, None, fx=0.5, fy=0.5, interpolation=cv2.INTER_AREA)
print(small.shape)
Fonctions
  • img.shape : Tuple (hauteur, largeur, canaux). Attention, dsize de resize est dans l'ordre inverse (largeur, hauteur).
  • cv2.resize(src, dsize, fx, fy, interpolation) : Redimensionne. Soit dsize=(largeur, hauteur), soit dsize=None avec les facteurs fx, fy. INTER_AREA convient pour réduire, INTER_LINEAR ou INTER_CUBIC pour agrandir.
